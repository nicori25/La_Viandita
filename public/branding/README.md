# Identidad de La Viandita

`la-viandita-logo.png` es la versión preparada con fondo transparente del logo aportado para el proyecto. Conserva la composición y los textos “La Viandita”, “PRECOOPERATIVA ESCOLAR” y “Mejor, entre todos.”.

Usar `src/components/BrandLogo.vue` para los puntos de identidad de la aplicación. El componente conserva las proporciones, incluye texto alternativo y resuelve la ruta base de GitHub Pages. Sobre fondos oscuros, usar un soporte claro para que el nombre y el lema sigan legibles. No estirar, recortar ni recolorear el logo completo.

La misma imagen se incorpora a las portadas, al informe imprimible y a los materiales de exposición. Los documentos originales anexados se conservan sin alterar.

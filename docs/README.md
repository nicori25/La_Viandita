# Documentación de La Viandita

Contenido funcional actualizado el 16 de noviembre de 2026. Identidad visual actualizada el 17 de noviembre de 2026 con el logo principal del proyecto.

- [Documentación completa — PDF, 43 páginas](La_Viandita_Documentacion_completa_actualizada.pdf): informe integrado, última consigna, tres visualizaciones e interpretación, tablero, seguimiento, simulación, cronograma, imprevisto, pruebas, correcciones, Supabase, conclusión y guion. Incluye los documentos originales y el seguimiento exportado como anexos.
- [Documentación editable — Word](La_Viandita_Documentacion_editable.docx): texto y figuras editables. Los anexos originales completos se conservan en el PDF.
- [Seguimiento de marzo de 2026 — PDF](Seguimiento_marzo_2026_generado_desde_el_sistema.pdf): exportación actual desde la aplicación, con el logo y datos ficticios del ejemplo.
- [Exposición — PowerPoint](Exposicion_La_Viandita.pptx): 14 diapositivas con identidad visual y notas del orador.
- [Exposición — PDF](Exposicion_La_Viandita.pdf): respaldo para presentar o imprimir.

Para descargar, abrir el archivo en GitHub y usar **Download raw file** (icono de descarga). Los datos simulados y las verificaciones pendientes están identificados. Las cuentas reales, el correo y la operación alimentaria no se presentan como probados cuando no hay evidencia de ello.

El logo de interfaz, portadas y exposición está en `public/branding/la-viandita-logo.png`; se documenta en `public/branding/README.md`. Los documentos originales anexados se mantienen sin alteraciones.
